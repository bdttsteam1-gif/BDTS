운영 데이터 옮기기

BDTS-main 의 구글 시트 백업 거래처이력카드.xlsx 를 넣으면 이 화면에서 바로 포털 형식으로 바꿔 Azure 에 넣습니다. 지금 Azure 에 든 자료를 지우고 새로 넣는 도구이며 관리자만 쓸 수 있습니다.

확인하는 중…

1 지금 Azure 에 든 자료 · 지울 저장소 고르기

먼저 건수를 세어 보여드립니다. 체크한 저장소만 즉시(휴지통 미보관) 비웁니다. 로그인·비밀번호·변경 이력은 이 화면에서 건드릴 수 없습니다.

2 거래처이력카드.xlsx 넣기

구글 시트에서 내려받은 거래처이력카드.xlsx 한 개를 넣으면 됩니다. (드래그해도 됩니다) 변환 결과와 검토 리포트를 여기서 바로 보여주고, 아무것도 Azure 에 쓰지 않습니다 — 3단계에서 실행하기 전까지는 안전합니다. (확정한 날짜 보정표 overrides.json · 값 정리표 value-map.json 이 더 있으면 xlsx 와 같이 넣으세요. 지금까지 확정한 내용은 화면에 이미 들어 있습니다.)

여기를 눌러 파일 고르기 거래처이력카드.xlsx (또는 manifest.json + 변환 JSON)

3 확인하고 실행

되돌릴 수 없습니다. 1단계에서 체크한 저장소는 휴지통을 거치지 않고 바로 비워지고, 2단계 파일이 있는 저장소에는 그 내용이 들어갑니다. 포털에 직접 입력한 자료도 함께 사라집니다.
